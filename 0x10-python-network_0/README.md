# Projet cURL et Scripts Bash

Ce projet contient des scripts Bash utilisant cURL pour effectuer diverses tâches liées aux requêtes HTTP. Il contient également une fonction Python pour trouver un pic dans une liste d'entiers non triés.

## Contenu du projet

- `0-body_size.sh`: Script pour afficher la taille du corps de la réponse en octets.
- `1-body.sh`: Script pour afficher le corps de la réponse d'une requête GET avec code de statut 200.
- `2-delete.sh`: Script pour envoyer une requête DELETE et afficher le corps de la réponse.
- `3-methods.sh`: Script pour afficher toutes les méthodes HTTP acceptées par le serveur.
- `4-header.sh`: Script pour envoyer une requête GET avec un en-tête personnalisé.
- `5-post_params.sh`: Script pour envoyer une requête POST avec des paramètres spécifiques.
- `6-peak.py`: Fonction Python pour trouver un pic dans une liste d'entiers non triés.
- `6-peak.txt`: Fichier contenant la complexité de l'algorithme de `6-peak.py`.

## Instructions

Assurez-vous que tous les scripts sont exécutables et testés sur Ubuntu 20.04 LTS.
